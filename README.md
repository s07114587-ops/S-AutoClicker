# S-AutoClicker

S-AutoClicker is a fast, lightweight, and customizable auto-clicker application designed to automate repetitive mouse clicks efficiently.

## Features
* **Customizable Click Interval:** Precisely set the time between clicks (hours, minutes, seconds, and milliseconds).
* **Multiple Click Options:** Choose between Left, Right, and Middle mouse button clicks.
* **Click Types:** Supports both Single and Double clicks.
* **Hotkey Support:** Start and stop the auto-clicker instantly using a customizable keyboard shortcut (e.g., `F6`).
* **Click Limits:** Choose to click continuously until manually stopped, or set a specific number of clicks to perform.

## Getting Started
1. Download and launch S-AutoClicker.
2. Configure your desired click interval, mouse button, and click type.
3. Press the designated Start/Stop hotkey to begin auto-clicking.
4. Press the same hotkey again to stop.
